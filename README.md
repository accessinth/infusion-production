# บันทึกงานอินฟิวชั่น · MARSHAL AEROPART

แอปบันทึกการผลิตแผนกอินฟิวชั่นสำหรับแท็บเล็ตหน้างาน เปิดผ่านเบราว์เซอร์ และใช้ Supabase เป็นฐานข้อมูล

**ลิงก์แอป:** https://accessinth.github.io/infusion-production/

## ลองใช้ก่อนติดตั้ง

เปิดลิงก์ด้านบนได้เลย ถ้ายังไม่ได้ใส่ค่า Supabase แอปจะทำงานใน **โหมดทดลอง** ใช้ข้อมูลตัวอย่าง และ PIN ของทุกคนคือ `1234`

## ติดตั้งใช้งานจริง

1. **สร้างฐานข้อมูล:** สร้างโปรเจกต์ที่ supabase.com แล้วเปิด SQL Editor วางไฟล์ `supabase/schema.sql` ทั้งไฟล์แล้วกด Run (รันซ้ำได้)
2. **สร้างบัญชีเครื่อง:** ไปที่ Authentication → Users → Add user แล้วติ๊ก Auto Confirm
   - บัญชีแท็บเล็ตหน้างาน ได้สิทธิ์ `station` อัตโนมัติ
   - บัญชีผู้บริหาร ให้รันคำสั่งยกสิทธิ์ที่อยู่ท้ายไฟล์ schema.sql
3. **ใส่ค่าเชื่อมต่อ:** ใน `src/app.html` แก้ `CONFIG` ด้วยค่า Project URL และ Publishable key (Settings → API Keys) แล้วรัน `python3 build.py`
   Publishable key ออกแบบมาให้อยู่ในหน้าเว็บได้ ข้อมูลถูกป้องกันด้วยสิทธิ์ในฐานข้อมูล (RLS)
4. **ขึ้นเว็บ:** push ขึ้น GitHub แล้วเปิด Settings → Pages → Deploy from branch (main, / root)
5. **เปิดบนแท็บเล็ต:** เปิดลิงก์ ล็อกอินด้วยบัญชีแท็บเล็ต แล้วกด แชร์ → เพิ่มไปยังหน้าจอโฮม
6. **ตั้งค่าข้อมูล:** ใส่ PIN ผู้บริหาร (เริ่มต้น `1234` ให้เปลี่ยนทันที) แล้วไปที่ ตั้งค่า เพื่อเพิ่มช่าง สินค้า สูตรมาตรฐาน และราคาวัสดุ
